# Neovim Config

My personal Neovim configuration.

Remote repository: https://github.com/Hex4C59/nvim-config

## Location

This repository is intended to live at:

```bash
~/.config/nvim
```

## Sync

Pull latest changes:

```bash
git pull
```

Commit local changes:

```bash
git status
git add .
git commit -m "chore: update nvim config"
git push
```
